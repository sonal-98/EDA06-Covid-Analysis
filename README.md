# COVID-19 Analysis

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a global COVID-19 dataset to understand the spread, severity, recovery trends, and regional impact of the pandemic. 
The dataset includes country-wise information such as confirmed cases, deaths, recoveries, active cases, new cases, weekly growth, WHO regions, and geographical coordinates.
The project began with data cleaning and preprocessing, where we identified and handled missing values, duplicate records, and incorrect data types to improve data quality.

## Objectives
Analyze confirmed COVID-19 cases across regions.
Examine deaths and recoveries.
Study changes in cases over time.
Calculate and compare outcome rates.
Identify WHO regions with significant case activity.
Analyze relationships between major COVID-19 indicators.

## Dataset
COVID-19 time-series and regional dataset containing confirmed cases, deaths, recoveries, and geographical/time dimensions.

## Analysis Performed
Data inspection and preprocessing.
Missing-value and duplicate analysis.
Date and geographical standardization.
Active-case and outcome calculations where applicable.
Regional comparison.
Death and recovery rate analysis.
Weekly trend analysis.
Visualizations
Top-region analysis

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Kaggle Notebook

## Key Skills

Time-Series EDA, Rate Calculations, Correlation Analysis, Data Cleaning, Aggregation and Visualization.
